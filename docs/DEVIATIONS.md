# Deviations from the original Onslaught 2

Every departure from the original game's behaviour is listed here with its reason and the
`RulesProfile` toggle that controls it. `RulesProfile.classic` keeps the original behaviour
for the regression suite; `classicFixed` (the v1 default) applies the rows marked "fix".
See `docs/REMASTER_PLAN.md` §2.6 and `.agents/rules.md` R10. Rows marked "(app)" are
departures in the app's flow or display, outside the simulation: they have no `RulesProfile`
toggle and no regression fixture can see them (owner decision, 2026-10-18). Rows marked
"(data)" are choices made once in the data snapshot where the original holds two values for one
thing; they have no toggle either, the generator writes the value the game used (owner decision,
2026-10-21).

"The original" is the 2350-gaby build in `.legacy/` (since 2026-10-20; it replaced 2221-nyehi,
see `docs/ONSLAUGHT2_GAME_REFERENCE.md` "Changes in 2350-gaby").
